## Proyectos
 
### [Empleos Carlos Paz](https://empleoscarlospaz.com.ar)
Bolsa de trabajo de Villa Carlos Paz y el Valle de Punilla, en producción. Atrae público orgánico desde los buscadores y suma más de 1.000 postulaciones, más de 700 perfiles y más de 100 empresas que publicaron.
 
- Postulación sin registro con carga de CV y cuentas opcionales para seguir cada postulación.
- Panel para empresas con avisos, recepción de CV y métricas de visitas.
- Medición del embudo de postulación con eventos, Google Analytics y Search Console.
- Control de acceso por roles con Row Level Security en PostgreSQL.
`Next.js` `React` `TypeScript` `Node.js` `PostgreSQL` `Supabase`
 
### [HydroVision](https://hydrovision.com.ar)
Proyecto final de carrera, co-desarrollado con [Adrián Ramírez](https://www.linkedin.com/in/adrian-alejandro-ramirez/). Hoy está en prueba en la Cooperativa Villa Santa Cruz del Lago. El operario fotografía el medidor de agua, la app propone la lectura y él la confirma o la corrige.
 
- App instalable (PWA) que funciona sin señal y sincroniza al volver la conexión.
- OCR con Google Vision y Tesseract.js en el celular como respaldo sin conexión.
- Panel con padrón de socios, rutas de lectura, plano de la red, avisos push, usuarios y roles.
- Requisitos especificados con OpenSpec, 17 decisiones documentadas como ADR, tests con Vitest y tres pruebas de campo.
`Next.js` `React` `TypeScript` `Node.js` `PostgreSQL` `Prisma` `Tesseract.js` `Leaflet` `Vitest`
 
### [Deploy Club, sistema de reservas](https://clubdeploy.online) (código público)
Trabajo práctico grupal de la carrera (equipo de 4, Scrum): reservas de canchas de tenis, pádel y fútbol 5. [Ver el código](https://github.com/rociobazan/club-deportivo-deploy).
 
- API REST con enfoque API-First, especificada con OpenSpec antes de programar.
- Git Flow, revisión de pull requests y CI/CD con GitHub Actions.
- Despliegue en AWS EC2 con Docker Compose.
`Next.js` `Nest.js` `PostgreSQL` `Docker` `AWS EC2` `GitHub Actions`
